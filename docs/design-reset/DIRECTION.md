# The Other Side of Default

Two standalone browser-rendered compositions were made before the rewrite. See `concepts/aperture.png` and `concepts/signal.png`. They are experiments, not additional production routes.

| Criterion | Typographic Aperture | Signal / Field Notes |
| --- | --- | --- |
| Silhouette | Three-line ink mass interrupted by a tilted arched void | Split white/ink editorial sheet |
| Two-second focus | Title and single portal | Two competing title/project blocks |
| Typography | Compressed structural letters, open body margins | Compressed annotation and oversized technical symbol |
| Color restraint | Paper/ink, one muted cool insert | White/ink, cyan path |
| Originality | Portal carries a question into another room | Familiar technical split-page geometry |
| Personal potential | Curiosity now; real portrait can replace reserved insert later | Mainly software-focused |
| Mobile | Title/portal can overlap above a separate clear reading strip | Long title and technical rail compete at narrow width |
| Performance | CSS silhouette, small vector outlines | Lightweight SVG trace |
| Distance from baseline | Entirely replaces four colored columns and blue project opening | Replaces columns, but resembles a conventional software panel |

Winner: **Typographic Aperture**. Its black arch and compressed headline read as one authored object. The prototype also exposed two defects to fix in implementation: the question card clips at its right edge and the scroll cue overlaps the portal. The production composition gives the card a smaller label and a dedicated bottom strip. Avoid the prototype's decorative registered trademark. The hero uses the configured nickname rather than a second brand constant.

Borrow from Signal: one original learning trace in the SAT exhibit. No cyan technical rails across every route. SAT uses citrus; Huquq uses plum and a ruled folio; the Gallery uses a charcoal mat and original monochrome print apertures.

Reference principles: receding room continuity (KIMI); identity/art layering (Marcus); tactile print and opposing rails (Jack). No reference code, photographs, protected exam questions, testimonials, metrics or models copied. The portal is original CSS geometry. Project illustrations are conceptual and labeled; genuine captures stay in work details.
